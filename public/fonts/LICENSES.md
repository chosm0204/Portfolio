# 폰트 라이선스

이 디렉터리의 웹폰트는 모두 SIL Open Font License 1.1 로 배포된다.

| 파일 | 서체 | 출처 | 라이선스 |
|---|---|---|---|
| `PretendardVariable.woff2` | Pretendard Variable | npm `pretendard` (orioncactus/pretendard) | SIL OFL 1.1 |
| `JetBrainsMono-Variable.woff2` | JetBrains Mono Variable (latin subset, wght) | npm `@fontsource-variable/jetbrains-mono` | SIL OFL 1.1 |

두 파일 모두 npm 패키지에서 추출해 self-host 한다. 2파일 이상 로딩하지 않는다.
