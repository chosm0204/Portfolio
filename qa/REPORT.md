## 7. 진입 효과 안전성

2026-08-31 추가. 스크롤 진입 효과를 넣으면서 **JS가 실패해도 내용이 사라지지 않는지**를 확인했다.
초기 상태(`opacity:0`)를 CSS에 두지 않고 스크립트 실행 시에만 주입하는 구조라, 스크립트가 돌지 않으면 아무것도 숨지 않는다.

헤드리스 크롬에 CDP로 붙어 측정했다.

| 상황 | 결과 |
|---|---|
| JS 비활성 (`setScriptExecutionDisabled`) | 홈 21/21 · CLUE 23/23 전부 보임 |
| `prefers-reduced-motion: reduce` | 전부 즉시 완성. 스크립트 중단 |
| 로드 후 감속 설정을 켠 경우 | 숨어 있던 19개 즉시 드러남 |
| 인쇄 | 홈 21 · CLUE 23 · DUDU 25 전부 보임 |
| **IntersectionObserver 고장 재현** | 가짜 관측자를 심어도 2초 타이머가 숨김 해제. 4.2초 시점 21개 전부 보임 |
| 재생 횟수 | 바닥까지 훑고 복귀해도 재생 안 됨 |
| LCP 요소 | 홈 초상 472ms — 진입 대상 아님 |
| 트랜지션 실측 | opacity 0→1, 14px→0, 474ms 완료 |

**관측이 죽어도 내용은 남는다**는 것이 이 구조의 핵심이다.
